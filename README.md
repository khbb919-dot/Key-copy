# تطبيق نسخ المفاتيح (Flutter)

مربع علوي بأبعاد ثابتة (340×190) يعرض خط المفتاح، وتتحكم به من دائرة أزرار في الأسفل.

## طريقة التحكم
| الزر | الوظيفة |
|------|---------|
| ◀ ▶ | الانتقال بين مواضع القطع (السهم ↓ يوضح الموضع المحدد) |
| ▲ | رفع الخط (عمق أقل) |
| ▼ | خفض الخط (عمق أكبر) |
| الزر المركزي | إعادة القطعة المحددة للعمق الابتدائي |

- الضغط المطوّل على الأسهم يكرر الأمر.
- العمق من 1 إلى 9، وعدد القطع من 3 إلى 10 (الافتراضي 5).
- يظهر الكود تحت المربع (مثل: `4 4 2 1 5`) ويمكن نسخه.

## التجميع عبر GitHub Actions
1. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات هذا المجلد كما هي (بما فيها `.github`).
2. افتح تبويب **Actions** ← **Build APK** ← **Run workflow** (أو يعمل تلقائيًا عند أي push).
3. بعد انتهاء البناء نزّل الملف من **Artifacts** باسم `key-copy-apk`.

> مجلد `android` لا حاجة لرفعه؛ يولّده الـ workflow تلقائيًا.
> ملف APK الناتج موقّع بمفتاح debug، ويصلح للتثبيت المباشر على الجوال.
